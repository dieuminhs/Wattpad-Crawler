<objective>
Restructure the render section of `archive_story()` so that:
1. All three renderers (TXT, HTML, EPUB) run unconditionally in their own try/except blocks (preserves existing per-renderer independence)
2. A `render_status: dict[str, str]` collects "ok" or "failed" per format
3. `story.done` is emitted with the `render_status` dict in its payload (per-format breakdown visible in SSE)
4. After the loop, if every renderer failed, raise `RenderError(f"all renders failed: {render_status}")`
5. `RenderError(Exception)` is defined alongside the existing `ResolveError(Exception)` in `jobs.py`

`RenderError` flows through `JobRunner._run`'s existing `except Exception` handler unchanged → the job ends `failed` with the error string. `archive_many` already catches per-story exceptions and records `failed: {e}` — same path; existing behavior preserved.

Purpose: Closes REL-04. A story where all three renderers fail no longer produces a job marked `done` with no output artifacts. The job ends `failed` with a clear error message, AND the per-format breakdown is visible in the SSE event stream so the user knows exactly which renderers blew up.

Output: Updated `local_story_archive/jobs.py` with `RenderError` and the restructured render section; new tests in `tests/unit/test_jobs.py` covering the all-fail and partial-fail cases.
</objective>

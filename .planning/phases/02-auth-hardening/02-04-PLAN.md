NOTES:
- The dedicated `except AuthFailedError` branch MUST come BEFORE the broad `except
  Exception`. Python catches the first matching except. If the order were reversed,
  AuthFailedError (which IS an Exception) would be caught by the broad branch and the
  re-raise would never happen.
- We DO update manifest with status=`failed` for the part that triggered the auth error
  (consistent with how the broad-except branch handles other failures). This way the user
  sees in `wattpad-crawler status` that the part ended in failed state, not in_progress.
- We do NOT call `logger.exception` in the AuthFailedError branch — the caller (JobRunner)
  will log the propagated exception. Avoid double-logging the same exception.
- The `raise` statement (no argument) re-raises the current exception preserving the
  traceback — standard Python idiom.

(c) **Important — do NOT add an AuthFailedError branch to `archive_many()`**.

Look at `archive_many()` at lines 229-252. It has its own per-story `try/except Exception`
at line 247 that catches anything from `archive_story()`. If a 401 hits during story 1's
archival, AuthFailedError will propagate up to `archive_many()`, get caught by the broad
except, and recorded as a failed story... and then `archive_many` will continue to story 2,
which will ALSO 401 immediately, etc.

Per D-18, the job-level loud failure is what we want. archive_many is invoked from CLI
batch commands AND from JobRunner. For:
- CLI library/list batch: D-18 says detection in client.get covers this; the FIRST 401 in
  fetch_library() (line 87 of cli.py) raises AuthFailedError BEFORE archive_many is even
  called. So CLI batch is already covered by Plan 03's CLI gate (validate_cookie at start
  of branch) AND by Plan 02's client.get branch.
- JobRunner library/list batch: same — fetch_library at routes.py:104 raises AuthFailedError

For the rare case where the cookie expires DURING a batch (after validate_cookie passed

catastrophic — every subsequent story would also fail loudly. We accept this for v1; a

def test_archive_story_propagates_auth_failed(output_dir: Path):
    """AUTH-04 / D-16: archive_story re-raises AuthFailedError instead of swallowing."""
    cfg = Config(output_dir=output_dir)
    manifest = Manifest(output_dir).connect()
    try:
        story = Story(
            story_id="42", title="Hi", author_username="bob",
            parts=[Part(part_id="100", ordinal=1, title="One", url="https://w/100")],
        )
        fake_client = MagicMock()
        deps = _make_deps(story)
        deps.fetch_chapter_html.side_effect = AuthFailedError(
            "Wattpad returned HTTP 401 for https://w/100",
            status_code=401,
            url="https://w/100",
        )
        with pytest.raises(AuthFailedError):
            archive_story(cfg, fake_client, manifest, "42", deps=deps)
        # Manifest should reflect the failure, not "done".
        row = manifest.get_part("42", "100")
        assert row["status"] != "done", f"Expected status != 'done', got {row['status']!r}"
    finally:
        manifest.close()


def test_archive_story_emits_auth_failed_event(output_dir: Path):
    """AUTH-04 / D-17: archive_story emits auth.failed event BEFORE re-raising."""
    cfg = Config(output_dir=output_dir)
    manifest = Manifest(output_dir).connect()
    try:
        story = Story(
            story_id="42", title="Hi", author_username="bob",
            parts=[Part(part_id="100", ordinal=1, title="One", url="https://w/100")],
        )
        fake_client = MagicMock()
        deps = _make_deps(story)
        deps.fetch_chapter_html.side_effect = AuthFailedError(
            "Wattpad returned HTTP 401 for https://w/100",
            status_code=401,
            url="https://w/100",
        )
        events: list[tuple[str, dict]] = []
        def collect(kind: str, data: dict) -> None:
            events.append((kind, data))
        with pytest.raises(AuthFailedError):
            archive_story(cfg, fake_client, manifest, "42", deps=deps, progress=collect)
        # The auth.failed event must have been emitted BEFORE the re-raise.
        auth_events = [(k, d) for (k, d) in events if k == "auth.failed"]
        assert len(auth_events) == 1, f"Expected exactly 1 auth.failed event, got {len(auth_events)}"
        kind, data = auth_events[0]
        assert data["part_id"] == "100"
        assert data["status_code"] == 401
        assert data["url"] == "https://w/100"
        assert "401" in data["message"]
    finally:
        manifest.close()
